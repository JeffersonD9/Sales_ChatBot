# Deprecated

`src/` ya no es una fuente activa de codigo productivo.

El codigo nuevo debe vivir en:

- `apps/*` para entrypoints y logica propia de cada servicio.
- `packages/*` para utilidades compartidas entre servicios.
- `infra/*` para configuracion de infraestructura.

Esta carpeta queda solo como marcador historico durante la transicion del repo.
